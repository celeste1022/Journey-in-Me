# 2. 连接设备

[打开线上 Demo](https://celeste1022.github.io/Journey-in-Me/connect-device/)

Journey in Me 冥想音箱连接流程的可点击演示，沿用 Paper Zen 风格与已确认的细线音箱插画。

## 体验路径

默认从首次登录后的绑定页开始：确认听到配对提示 → 扫描 → 选择 Wi-Fi、填写密码 → 连接成功 → 检查固件 → 下载、安装、重启 → 完成并回到 Home。没有新固件时直接回到 Home。

Wi-Fi 列表在页面内展开；切换网络会清空密码，关闭列表和失败后取消会保留输入。扫描等待 10 秒后出现提示，30 秒超时。绑定页返回 Home 时显示未连接。

“演示情景”可以体验扫描较慢或超时、没有 Wi-Fi、配网失败、没有新固件、固件检查失败、下载不稳定、文件损坏、安装时断电等分支。“Later”回到 Home 并保留待更新状态；恢复后根据模拟设备状态继续。可选择 4× 演示速度或“快进等待”。手机上的演示控制位于页面下方。

蓝牙、Wi-Fi 和固件更新均为模拟，不会连接或修改真实设备。密码只保存在当前页面内存中，不发送到服务器，不写入浏览器存储；请填写任意演示密码。

## 本地预览与校验

无需安装依赖或构建：

```sh
cd Speaker-Connection
python3 -m http.server 4187 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:4187/`。

```sh
node --test tests/flow.test.mjs
```

15 项状态测试覆盖完整路径、计时、输入保留、重复提交、失败后重试、Later 及断电恢复。桌面及 390/320 像素手机尺寸的点击流程已另行通过浏览器验证。

`dist/flow.mjs` 为流程状态机，`dist/app.mjs` 负责界面和交互，`dist/styles.css` 为响应式样式。发布时仅将 `dist/` 内容复制到 `/connect-device/`，资源均使用相对地址。

# My Friends Demo

[打开公开 Demo](https://celeste1022.github.io/Journey-in-Me/my-friend/)

好友画卷、全屏拖动、练习记录、共同回忆长卷、好友申请、立即与预约练习邀请，以及轻柔交互动效。

纯静态页面，直接打开 index.html 即可。所有好友和消息为示例数据；不会发送真实请求。操作状态只在当前页面内保留，刷新会重置。遵循系统减少动态效果设置。

代码保存在 My-friend 分支。发布工作流保留 main 分支的 Create Demo 在站点根目录，把此 Demo 放到 /my-friend/。

## Immersive practice room

接受立即练习邀请可进入全屏练习室：纸感底色、水彩山影与缓慢呼吸起伏、所有成员头像、到场与准备状态、房主开始、缺席确认、倒计时与完成状态。支持关闭环境动效及系统减少动态效果。

右侧场景控制可模拟原发起人到场、房主离开、六人房间和练习完成。至少两人到场且所有到场者准备后才能开始；开始前原发起人到场会接任房主，房主离开按进入顺序转交。此版本为本地状态与视觉演示，无实时多人连接及课程音频。
